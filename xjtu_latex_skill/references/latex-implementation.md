# Word 要求在 LaTeX 中的实现

从 `assets/thesis.tex` 复制最小骨架，以 XeLaTeX 编译。下面的命令是实现入口，不是对渲染结果的免检证明；字体度量、Word 行距与 LaTeX 行距不同，须以 PDF 页面为准。

| Word 模板要求 | LaTeX 实现与核验 |
| --- | --- |
| A4，镜像页边距：上 3.0、下 2.5、内外 2.6 cm | `ctexbook[twoside,openany]` 与 `geometry` 的 `top`、`bottom`、`inner`、`outer`。第一章前显式 `\cleardoublepage`，普通章节保留 `openany`。 |
| 页眉边界距 2.0 cm、页脚 1.75 cm | 骨架中的 `headheight`、`headsep`、`footskip` 是几何近似；用 PDF 实测页眉文字和页码位置。 |
| 宋体中文、Times New Roman 西文 | XeLaTeX 的 `fontspec`/`xeCJK` 字体设置；编译日志若提示缺字或字体替代，应安装所需字体或在用户允许下改用字形接近的替代字体，并在结果说明。 |
| 小四号、1.2 倍行距、首行缩进 2 字符 | `\zihao{-4}`、`\setstretch{1.2}`、`\parindent=2em`。与 Word 模板相比仍要逐页调节行距及段落高度。 |
| 三级标题与目录 | `\ctexset` 配置章、节、小节字号和间距；`\setcounter{secnumdepth}{2}`、`\setcounter{tocdepth}{2}`。`\tableofcontents` 自动生成页码；至少编译两次。 |
| 奇偶页页眉及外侧页码 | `fancyhdr` 的 `CO/CE` 页眉、`RO/LE` 页脚；同样定义 `plain` 页式以覆盖章首页。正文前先切大写罗马页码，第一章前切阿拉伯页码。 |
| 图、表、公式按章编号 | `\thefigure`、`\thetable`、`\theequation` 使用章号和短横线；`caption` 控制题注五号。引用均使用 `\label`/`\ref` 或 `\eqref`。 |
| 三线表 | `booktabs` 的 `\toprule`、`\midrule`、`\bottomrule`，宽度用 `tabularx` 或其他可伸缩表格控制到 `\textwidth`；不用竖线和密集网格。 |
| 参考文献 | 新稿可用 `natbib` 的数字上标引用；真实文献较多时可接入符合所需著录规则的 BibTeX/Biber 样式，保留引用顺序。作者—年份体系只能整篇一致切换。 |
| A3 封面和后附表格 | 这类学校制式资产由用户或学校提供，单独按原件并入最终 PDF 或交给印制流程；不能用骨架中的普通标题页冒充。 |

## 页面与目录

- 摘要与英文摘要各从新页开始。主要符号表可选，目录须从奇数页开始；正文第一章从奇数页开始。正文第一章之后的章只换页，避免不必要的空白偶数页。
- 目录题名须为“目  录”、三号宋体；条目小四号，章顶格、节缩进一字符、小节缩进两字符，点线引导到右侧页码。骨架用 `tocloft` 配置；目录宽度、长标题换行和页码对齐必须检查 PDF。
- `\chapter*` 不会自动进入目录，也不会自动更新奇数页页眉。摘要、致谢、参考文献等无编号部分需显式写目录条目并更新页眉，避免目录缺项或显示上一章标题。
- 若主要符号表置于目录之前，普通 `\addcontentsline` 可以在后续目录中显示；若沿用原文件示例顺序，仍要核对页码和奇偶页。

## 图表、公式和引用

- 使用图或表前，先在正文中用 `\ref` 引出，再将浮动体放在附近。图题放在 `\includegraphics` 后，表题放在表格前；图中文字通常五号，最小七号。示例图尺寸 6.67 × 5.00 cm 等只是 Word 模板中的推荐值，同类图尺寸应一致。
- 用他人图表须有真实来源，图题或表题右上角标注引用；分图用 `(a)`、`(b)` 等，各有分题注，最下方为总题注。不能仅因排版完成而省去出处。
- 公式另行居中，编号右侧。`\eqref` 的默认半角括号与模板全角括号不同，骨架重定义编号样式；编译后应确认正文引用也与编号一致。公式后“式中”顶格解释符号，以分号分隔。
- 表格跨页时使用合适的长表格环境，重复表号、`（续）`、表头和单位说明。`tabularx` 本身不跨页，不能强行挤压长表。
- 参考文献不得用骨架占位条目填充。引用过的须入表，未引用的不得混入；模板说一般不少于 30 篇、近五年文献为主，以真实研究情况核对。

## 附录与装订

附录用 `\appendix` 后的 `\chapter` 编排，标题显示“附录A”等；附录图、表、公式另编 `附录A-图1`、`附录A-表1`、`（附录A-1）` 等序号。不同 `ctex` 版本的附录题名可能不同，必须检查 PDF。附录、外文原文/翻译、图纸、程序以及学校提供的任务书、考核评议书、评审意见书、答辩结果与正文页码接续；学校指定的后附表格从奇数页起排。

## 编译与检查

一般运行 `xelatex thesis.tex` 两次；若使用 BibTeX/Biber，在两次 XeLaTeX 之间执行对应文献命令，直到引用和目录页码稳定。检查日志中的 `Undefined control sequence`、`Missing character`、`Citation undefined`、`Reference undefined`、`Overfull` 及字体替代。随后逐页查看 PDF：字形、页边距、奇偶页页眉、双横线、页码、标题、目录、图表与附录均要与 Word 原模板对照。没有编译器时只能报告源码的静态检查，不能宣称 PDF 已通过验证。
